Fonctionnalités

De la première recherche à ton installation.

Career OS suit chaque étape : trouver, postuler, relancer, décider, puis s'installer. Sans jamais inventer une information.

◎

Recherche guidée

Décris ce que tu veux : Claude prépare la recherche, interroge les sites d'offres et les pages carrières des entreprises que tu suis, puis range les résultats.

✓

Candidatures et relances

Pipeline, relances planifiées, entretiens, documents envoyés (la version exacte), contacts et échéances dans un tableau de bord.

✎

CV façon Canva

Glisse, aligne, écris : un éditeur visuel avec guides d'alignement. Demande à Claude de raccourcir, traduire ou adapter ton CV à une offre.

⚖

Offres et contrats analysés

Ce qui correspond à ton profil, ce qui manque, les clauses à vérifier et les questions à poser. Une analyse descriptive : la décision reste la tienne.

⌂

Installation à l'étranger

Logements comparés sur une carte, budget et épargne, démarches officielles par pays (Belgique, Suisse, Canada, Royaume-Uni…) avec leurs liens.

Avec Claude

Un assistant qui agit, pas un formulaire de plus.

Career OS se pilote en langage naturel, depuis l'application ou depuis Claude Code.

Dans l'application

Une barre de discussion sur chaque page. « Ajoute cette offre », « prépare mon entretien chez Acme », « compare mes trois meilleurs logements » : Claude lit, prépare, et te demande avant de modifier quoi que ce soit d'important.

Depuis Claude Code

Career OS expose ses outils à Claude Code. Colle un e-mail de recruteur ou un PDF d'offre : Claude met à jour la candidature, planifie l'entretien, rédige la relance.

Ton abonnement, pas de surcoût

L'IA passe par ton Claude Code (abonnement Claude) ou une clé d'API. Sans IA, l'application fonctionne quand même.

Installer

Trois étapes, Claude s'occupe du reste.

Claude Code installe et configure Career OS pour toi : il te demande qui tu es et ce que tu cherches, crée tes dossiers, lance l'application et remplit ton profil à partir de ton CV.

Télécharge le projet

Avec git, ou en ZIP depuis GitHub.

git clone https://github.com/Miche1-Pierre/career-os.git

Ouvre-le dans Claude Code

Dans le dossier téléchargé :

cd career-os && claude

Demande l'installation

Écris simplement :

« installe Career OS »

Il te faut Node.js 22 ou plus et Claude Code. Docker est facultatif : sans lui, la base de données est un simple dossier sur ton disque.

Questions

Bon à savoir.

Où sont stockées mes données ?

Sur ton ordinateur, dans un dossier que tu choisis à l'installation (par défaut Documents/CareerOS) : tes documents, la base de données et les sauvegardes quotidiennes. Rien n'est envoyé sur un serveur Career OS : il n'y en a pas.

Faut-il Docker ?

Non. Sans Docker, la base de données (PostgreSQL) tourne dans l'application et s'enregistre dans ton dossier. Si tu utilises déjà Docker, l'installation peut s'appuyer dessus.

Faut-il un abonnement Claude ?

Pour l'installation guidée et l'assistant, oui : Career OS utilise ton Claude Code, ou une clé d'API Anthropic. Sans IA, tu peux tout gérer à la main dans l'application.

Claude peut-il envoyer des candidatures ou des e-mails à ma place ?

Non. Claude prépare les brouillons, les recherches et les analyses ; c'est toi qui envoies et qui valides chaque décision importante. Il ne remplit jamais un formulaire externe.

Et sur un serveur, pour y accéder de partout ?

C'est possible : une configuration Docker avec HTTPS et jeton d'accès est fournie dans le dépôt (docs/DEPLOYMENT.md).
